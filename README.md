# משבצת (Mishbetzet)

School timetable system: weekly schedule generator, conflict checks, daily substitutions, exams and special events, Excel import/export, and an AI scheduling assistant.

## Status

This is the code of the Claude artifact, imported as-is. It is a single self-contained page (`index.html`): plain JavaScript, HTML and CSS, no build step.

It depends on the Claude artifact runtime (`window.claude`) for its database, user identity, file downloads and AI calls, so it does not run fully outside Claude yet.

## Branches

- `master` – stable version
- `dev` – integration branch; feature branches are merged here through pull requests
